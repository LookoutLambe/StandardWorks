# Third-party lexical data

## Brown-Driver-Briggs / Strong's — `bdb_roots.js`

`bdb_roots.js` maps each Strong's number to its Brown-Driver-Briggs root. It is
generated by `tools/build_bdb_roots.js` from **LexicalIndex.xml** in
[openscriptures/HebrewLexicon](https://github.com/openscriptures/HebrewLexicon),
which aligns the identifiers of BDB, Strong's and TWOT.

The text of *A Hebrew and English Lexicon of the Old Testament* (Brown, Driver
and Briggs, 1906) and of Strong's Hebrew Dictionary is in the **public domain**.
The XML edition is © OpenScriptures and released under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Shoroshim — `shoroshim_roots.js`

`shoroshim_roots.js` is a Hebrew verb-root inventory extracted by
`tools/extract_shoroshim.py` from *SHOROSHIM: The Ultimate and Unique English
Thesaurus of Hebrew Verb Roots*, compiled by **Reuven Brauner**, © 2014,
Raanana, Israel. Only the root list is stored — no definitions — and it is used
as a validation set for the root resolver. The source PDF is not in this
repository.
